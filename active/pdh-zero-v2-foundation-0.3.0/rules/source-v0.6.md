## 1. 总体判定与计分原则

### 1.1 分开处理胡牌资格、成立标签与计分

先验证牌张和事件合法性，再建立完整胡牌结构解释，确认至少一个基础大胡成立，然后识别兼容牌型、执行等级选择和包含去重，最后加入符合条件的附加项。

门清、一条龙、海底、杠上开花不在本稿中被提升为独立大胡。只有这些附加条件而没有基础大胡，仍不得胡牌。花色或幺九牌种范围也不能替代合法胡牌结构。

同一手牌有多个合法解释时，分别计算，不跨不兼容解释拼接计分。是否选择其中最高计分解释，仍见Q6。

### 1.2 去重与叠加

- 已被更完整计分项包含的项目不再次计分，但保留成立标签与排除理由。
- 额外条件兼容且可同时实现时，可以按已明确关系叠加。
- 同一牌型家族的等级不累计。
- 混碰、清碰、混一色幺九等组合名称不再额外贡献一份分数。
- 用户明确允许的叠加关系优先于简单的集合包含猜测。例如十八罗汉的四暗杠单骑分支明确可以叠四暗刻单骑。
- 多项组合不仅要逐对兼容，还必须属于同一可实现的完整结构。

## 3. 牌型关系

### 3.1 已明确关系及同族等级

| 条件 | 处理 |
|---|---|
| 普通四暗刻／单骑同时符合碰碰胡 | 四暗刻计10／13，碰碰胡不加3 |
| 四暗刻 + 混一色／清一色／字一色 | 分别叠3／6／20，不再通过混碰或清碰加回碰碰胡 |
| 幺九／混一色幺九／清幺九 | 不另加碰碰胡；可以叠合法四暗刻档或合法七对家族等级 |
| 混一色幺九 | 9+3=12，不是9+3+12 |
| 清幺九 | 对应基础20，不是20+9 |
| 七对家族 | 只计4／8／16／32中的对应等级 |
| 普通四暗刻与单骑 | 只计10或13，不计23 |
| 普通十三幺与十三面 | 只计13或16，不计29 |
| 四个暗杠、单吊将牌，满足十八罗汉 | 十八罗汉32 + 四暗刻单骑13 = 45 |
| 十八罗汉的合法事件附加 | 杠上开花、海底各+3；海底使用真实胡牌补张取出前的剩余数，补牌合法性与墙端另验 |

十八罗汉不再加碰碰胡3，属于S4“包含项不重复计分”在其四杠结构上的直接推导；S5明确了四暗刻单骑可叠加的专项关系。

混一色、清一色、字一色按已给严格牌种定义互斥，不把字一色又分类为清一色或混一色。

### 3.2 幺九范围与胡形分支

S5明确允许幺九系列叠七对／豪七。因此不能把“先满足四刻一将”写成所有幺九的唯一入口，再把七对分支错误拒绝。

应分别验证：

1. 标准面子分支：幺九牌种范围内的合法四面子一将。由于没有2～8，序数顺子不能成立，面子自然为刻／杠；不再加碰碰胡。
2. 七对家族分支：同样满足幺九牌种范围，但使用七对及豪七等级的完整结构；不得要求同时拆成四刻一将。

七对分支和四暗刻分支不得强行拼接为一个胡形。碰／声明杠已经破坏七对结构时，不能以手中原先有四张相同牌继续计豪七。

典型小计，均排除其他未列牌型与事件：

| 组合 | 小计 |
|---|---:|
| 幺九 + 普通四暗刻 | 9+10=19 |
| 混一色幺九 + 四暗刻单骑 | 9+3+13=25 |
| 清幺九 + 四暗刻单骑 | 20+13=33 |
| 混一色幺九 + 普通七对 | 9+3+4=16 |
| 清幺九 + 豪华七对 | 20+8=28 |
| 清幺九 + 双豪华七对 | 20+16=36 |
| 清幺九 + 三豪华七对 | 20+32=52 |

结构推导：清幺九只有一九万、一九筒、一九条6种牌。普通七对的最低档需要7种不同对子，故在每种牌最多4张的14张七对结构中，清幺九七对至少含一组四张相同牌，最低实际为豪七档。不能制造“清幺九20+普通七对4=24”的有效牌例。

结构推导：清幺九同时清一色只剩同一花色的1与9两种牌，最多8张，不能满足14张胡牌结构。名义上的关系表不能产生物理上不存在的26倍清幺九清一色牌例。

两个合法牌种与对子结构算例：

- `11万 99万 东东 南南 西西 中中 发发`：14张、七种对子，同时符合混一色幺九，所列项目计9+3+4=16。
- `1111万 99万 11筒 99筒 11条 99条`：14张、一个四张组与五个对子，清幺九豪七所列项目计20+8=28。

Q1仍需确定：普通幺九是否必须同时含序数幺九与字牌，是否必须1与9都出现，以及全字牌与幺九的分类／覆盖关系。不得给全字牌自动同时加20+9。

### 3.3 十八罗汉

四个已成立杠后，获胜物理牌数为18张（16张杠牌与2张将牌）；胡前为四杠与一张将牌等待状态。所有杠均为暗杠且为单吊听牌时，S5明确允许叠四暗刻单骑。

| 组合 | 所列项目小计 |
|---|---:|
| 十八罗汉 + 四暗刻单骑 | 45 |
| 上述组合 + 杠上开花 | 48 |
| 上述组合 + 海底捞月 | 48 |
| 上述组合且海底、杠上开花均合法成立 | 51；必须有合法杠后补牌自摸，且该补张取出前牌山≤4；不能在事后翻马后反推海底 |

不能因为十八罗汉倍数高就覆盖用户明确允许的四暗刻单骑；不能另外增加碰碰胡3或通用门清3。并非任何十八罗汉都有13倍加分：存在明杠／由碰升级的加杠时，不能满足四暗杠单骑这一条件。

### 3.4 十三幺与十三面

十三面胡前牌种明确为：东、南、西、北、中、发、白、一万、九万、一筒、九筒、一条、九条，各一张。实际胡牌后，13种牌齐全，恰好一种成为一对。

十三面16与普通十三幺13为等级区别，不相加。判定需要胡牌前状态，不能仅凭最终“十三种加一对”区分两档。

“往往会寻求自摸”作为用户描述的策略倾向记录，不改写为“只许自摸”或“自动拒绝接炮”。十三面的接炮许可、过胡限制及与海底等事件附加的兼容范围仍见Q5。

普通十三幺胡前“已有一对、缺一种”的识别形式是待核的具体化，不仅凭其他地区惯例写死。十三幺家族不套用四刻一将；也不能只因其牌种是幺九字就自动加幺九9。用户使用“几乎独立”，尚未给出完整例外清单。

## 4. 门清附加专项

分开记录无碰杠历史、牌型自身的门清／暗结构要求、普通清／混门清+3资格。

门清+3必须先有合法大胡，以符合条件的单纯清一色或混一色计分，并且全程没有碰、明杠、暗杠和加杠。一条龙、海底作为附加项本身不取消资格。七对、混碰／清碰、四暗刻、幺九等其他基础大胡不能借同时符合清／混，再作为“单纯清／混”获得门清3。

| 场景 | 所列小计 |
|---|---:|
| 单纯混一色，无碰杠 | 3+3=6 |
| 单纯清一色，无碰杠 | 6+3=9 |
| 上项同时一条龙 | 6+3+3=12 |
| 无碰杠单纯混一色，同时海底 | 3+3+3=9 |
| 无碰杠单纯清一色，同时一条龙与海底，事件合法 | 6+3+3+3=15 |
| 清一色发生碰，同时一条龙 | 6+3=9，无门清；仍要验证一条龙结构可成立 |
| 清一色暗杠后杠上开花 | 6+3=9，无门清 |
| 未副露混碰／清碰 | 分别6／9，不额外加门清 |
| 普通结构但无基础大胡，无碰杠 | 不可胡 |

### 4.1 海底捞月（S7、S8已明确）

海底捞月是事件附加，不创造基础大胡资格。只允许自摸，点炮胡与抢杠胡不享受本项。沿用S7的“≤4”范围，S8将计数时点明确为**实际胡牌摸张取出之前**。不是只认恰好4张，也不是按摸后剩余数计算。

记W_before为本次实际摸牌前牌山剩余牌数。合法自摸且1≤W_before≤4时满足海底事件条件；W_before=0不能再发生一次普通合法摸牌，不能只用数值≤4凭空产生海底。

| 条件 | 海底判定 |
|---|---|
| 摸前5张、摸后4张，自摸且基础大胡成立 | 不算海底，S8明确的反例 |
| 摸前4张、摸后3张，自摸且基础大胡成立 | 海底+3 |
| 摸前3／2／1张，对应摸后2／1／0张，自摸且基础大胡成立 | 均满足摸前≤4 |
| 点炮或抢杠胡，牌山仅剩0～4张 | 不计海底 |
| 仅满足海底事件，没有合法基础大胡 | 不可胡 |
| 合法杠后补牌自摸，补张取出前牌山≤4 | 按已确认兼容关系，海底与杠上开花各+3；仍须先验证该杠和补牌合法 |

同时记录摸前和摸后数，但只用摸前数执行海底阈值。不能用结算翻马、新局发牌或专门开马阶段改变过的牌数反算海底。海底自摸后旧墙至多剩3张，低于正常最少N=6，抓马需走第7.3节的不足分支或第7.4节适用的专门开马分支；海底不取消抓马，未知马数不当作0。

## 6. 玩家身份、庄位与马牌位置

### 6.1 固定身份与当局相对编号

玩家身份和物理座位固定保存。当局庄家编号为0，从庄家起逆时针为0、1、2、3。初始东风座位为起始庄家，不意味着之后永远以东风为0。

庄家变化时，相对编号与马牌归属随之变化，但玩家累计得分、模型身份和牌谱身份不得换人。

例如固定逆时针座位为甲乙丙丁，甲为庄时甲乙丙丁编号0、1、2、3；下局乙为庄时乙丙丁甲编号0、1、2、3。原始终局必须同时保存本局庄家和下局庄家。

### 6.2 马牌归属表（S5已明确）

| 当局相对位置 | 序数牌 | 字牌 | 不同牌种数 |
|---|---|---|---:|
| 0：庄家 | 一、五、九万／筒／条 | 东、红中 | 11 |
| 1：庄家下家 | 二、六万／筒／条 | 南、发财 | 8 |
| 2：庄家对家 | 三、七万／筒／条 | 西、白板 | 8 |
| 3：庄家上家 | 四、八万／筒／条 | 北 | 7 |

这张表覆盖全部34种牌且不重不漏。11、8、8、7是依据表格得到的牌种计数；并不意味着每局剩余牌墙按此比例分布，也不能假设每个位置中马概率相同或把m固定替换成翻牌数除以4。

S6已经明确：只统计胡牌者按**计分所属局的相对庄位**命中的牌，每张命中算一只马。相同牌种翻出多张时逐张累计，不按不同牌种去重；其他位置的马不计入本次赢家的m。同一口径适用于旧墙、下一把手牌及专门开马来源。

记赢家在本局的相对编号为r，已翻出的每张马牌为h_j，表中牌到位置的映射为owner，则：

m = Σ_j 1[owner(h_j) = r]

本局1号胡，本局中马始终按二／六万筒条、南／发财计算。正常同局取马时可先完成结算，再进入下局。旧墙不足要求张数而使用下一把手牌时，允许先按赢家坐庄规则安排下一局发牌，再完成上局金额；但上局相对编号必须冻结，不能因已成为下局0号而改数一／五／九、东／红中。专门开马也结算上局，不更新一次相对编号。下一局本身发生的胡牌，才按下一局当时位置单独算马。不得重复计数或重分配同一次结算的马。

## 7. 翻马数量、连庄状态与取马来源

### 7.1 连庄累计规则

取马要求张数为N=2n+6，n为本次胡牌结算使用的连庄场数。首次胡为0。N是要求开马张数，不是命中数m。在已定义且可完成的三个取马分支中，实际开马张数K均等于N；不能因旧墙不足或换来源而截为6、14或旧墙剩余数。牌源优先级见第7.3节，旧墙不足且N>14的专门开马见第7.4节；极端N超过一副牌容量的处理仍待确认。

| n | 正常要求取马张数N |
|---:|---:|
| 0 | 6 |
| 1 | 8 |
| 2 | 10 |
| 3 | 12 |
| 4 | 14 |
| 5 | 16 |

已经明确：初始东风为庄；单赢家成为下一局庄；闲家胡牌，本次n=0，旧庄的累计数不转给新赢家；初始庄家首次胡也为0。

S7明确流局保留已有累计连庄状态，既不增加，也不清零；流局后同一庄家再次胡，继续加1。用户的0+1+0+1表示每个事件的增量，不是四次分别使用的连庄值。

| 事件 | 本事件增量 | 事件后累计n | 本次正常要求马数 |
|---|---:|---:|---:|
| 甲首次胡 | 0 | 0 | 6 |
| 甲再次胡 | +1 | 1 | 8 |
| 流局，甲继续坐庄 | 0 | 1 | 无胡牌抓马；本条不定义其他流局付款 |
| 甲又胡 | +1 | 2 | 10 |

以上最后的N=10。若旧墙不足10张，按S9取下一把赢家自己的原始前10张，不能固定取6，也不能混用旧墙余牌补数。专门开马与为结算而再洗牌不算一次胡或一次流局，不再增加n。

实现需区分“初始庄家尚未胡过”和“已经首次胡、n=0”；建议分别记录庄家ID、该任庄家是否已有首次胡、累计n。流局保存这三个状态；同一庄家再次胡且已经有首次胡时，先得出本次n+1，再据此计算N。换赢家则新赢家本次n=0。

### 7.2 各种胡法统一使用最后摸牌锚点

普通自摸、点炮、抢杠和杠后补牌均以**胡牌裁决前最后一次实际摸牌的位置**为锚点，按用户规定的牌山顺序取其后N=2n+6张。锚点那张牌本身不在马序列内。普通首次自摸就是胡牌摸张之后6张。

| 胡牌事件 | 应保存的锚点 |
|---|---|
| 普通自摸 | 本次实际胡牌摸张 |
| 点炮胡 | 点炮胡成立前最近一次实际摸牌，不以弃牌实体本身重新定位 |
| 抢杠胡 | 抢杠胡成立前最近一次实际摸牌；尚未发生的杠后补牌不能成为锚点 |
| 杠上开花 | 实际发生且导致自摸的杠后补牌 |

连续碰牌期间若没有新摸牌，不能凭发生碰或弃牌就更新“最后摸牌”位置。最后摸牌者不一定是赢家或点炮者。

实现需记录摸牌事件序号、玩家、牌实体、墙端和取牌位置。若普通摸牌与杠后补牌来自不同墙端，其“之后”的物理顺序仍需与发牌／取牌方向定义共同明确；不能假定数组下标+1永远等于真实后继，也不能抽到已经离墙的牌。

### 7.3 取马数量与牌源优先级（S8、S9已明确）

记R为胡牌后、按最后摸牌锚点及有效取牌顺序可供开马的旧墙剩余牌数，N=2n+6。**先检查R是否足够N，再在旧墙不足时检查N是否超过14。** 14只决定旧墙不足时能否使用下一把起手牌，不是所有开马的统一上限。

| 判断顺序 | 条件 | 牌源与数量 | 对下一局的影响 |
|---|---|---|---|
| 1 | R≥N，不论N是否超过14 | 从旧墙最后实际摸牌位置之后按规定顺序取足N张 | 本次无需借用下一把手牌，也不因N>14强制专门开马 |
| 2 | R<N且N≤14 | 旧墙余牌不计入本次马序列；使用下一把赢家自己手牌的原始前N张 | 只亮其中命中的马；这些牌仍为下一把真实手牌 |
| 3 | R<N且N>14 | 旧墙余牌不计入本次马序列；专门用一副牌开够N张 | 结算后重新洗牌再开打，不额外增加连庄 |

上述三个条件互斥；普通可实现情形下实际取数K=N。若专门开马要求超过一副牌容量，执行方式尚未确认，不由本表授权循环补牌、放回抽样或自行封顶。

**S9直接确认的两个边界：**

- n=2、N=10、R=7：旧墙7张不作数，取下一把赢家原始前10张；不是前6张，也不是旧墙7张加新局3张。
- n=5、N=16、R=20：直接从旧墙取16张；不因16>14而改用专门开马。

R=N也属于旧墙足够；N=14不属于超过14。例如N=14、R=13时使用下一把前14张；N=16、R=15时进入专门开马分支。上述结论均由同一张优先级表决定，不另建互相冲突的规则。

**下一把原始前N张的选取与公开性：**

- “前”是原始发牌到手顺序，不是理牌排序后的前几张；不得挑选有利牌替换。
- 选择完整前N张进行命中判定；没有命中的牌仍占用开马张数，不能继续摸到凑够N只命中马。
- 只需要亮出其中命中的马牌，未命中牌的具体身份不因开马而全部公开。
- 所有被用于判马的原始前N张仍为赢家下一把真实手牌；亮出的牌可以继续正常行牌，该公开事件不是碰、杠、弃牌或一次额外摸牌。
- 必须保存实体牌引用，不能把同一张亮马既计为手牌又计为牌河中的另一张实体。
- 计马始终使用计分所属局的赢家位置，不能因下一把赢家已经坐庄而重分配马牌。

要求N和实取K分别记入审计记录，验收时核对K=N；少取、多取或混合旧墙与新局牌源均不能静默作为正常完成。物理取牌方向见Q10c；散场没有下一把时的处理仍见Q13。

### 7.4 旧墙不足且N>14：专门开马后重新洗牌

S8规定专门开够相应张数后重新洗牌开打；S9进一步明确**本分支只在R<N且N>14时采用**。旧墙足够时始终优先取旧墙，即使N=16或更大也不因张数本身强制专门开马。N=14不属于超过14；n=4对应14，n=5对应16。

本稿将该过程记录为“专门结算阶段”，不擅自解释为必须额外购置另一副牌，也不把它伪造为一局实际对打。该阶段的牌用于上局结算；之后实际对局使用重新洗牌产生的牌序列，不能把用于开马的牌序列直接接着当作下局发牌。

例如已按本次胡牌得出n=5、N=16，旧墙R=15不足，执行专门开马后再洗牌，进入下一次实际对局时仍保留该n=5；不能因多洗了一次牌变成n=6。胡牌事件本身应有的连庄更新仍照7.1执行，这里只是禁止重复增加。

马数m继续按上局赢家位置计，付款仍计回上局；下局庄家按已有赢家坐庄规则，不因这个阶段多轮换一次。单副牌超过自身牌张容量时如何继续开马尚未给出，不生成重复抽取、无限牌源或截断N等默认实现。

### 7.5 亮马留手带来的公开信息

S8明确亮出的仅为命中马，不是全体候选牌。下一把对手可以使用这些已公开的牌种和持有人信息，这是合法公开信息；未命中牌的完整身份不能从私有审计区传给对手Actor。亮牌之后继续留手，不改变门清／碰杠历史。

若上局赢家为1号，下一把原始前6张是`二万、六筒、南、四条、东、九万`，上局m=3，只需亮二万、六筒、南；六张仍全部为该玩家下一把手牌。不能因该玩家已是下局0号而改亮东、九万作为上局命中马。

以实际公开的信息为限：候选张数K和完整命中数m都已公开时，可以得出未亮部分共有K−m张且不属于上局命中集合这一类别约束；不能据此得出每张未亮牌的身份，也不能把该约束施加到未参与开马的其他起手牌。若这些数量是否对外公开尚无实际界面证据，观察投影按明确公开事件逐项处理，不伪造牌位信息。

专门开马后发生重新洗牌时，旧开马牌的顺序不再是实际下一局的已知手牌位置。审计日志保留该序列用于重放结算，但不把已被新洗牌打散的位置关系当作下一局的确定信息。

## 8. 普通单赢家付款

### 8.1 基本公式（S5已明确）

记b为底分（默认1），F为去重叠加后的胡牌倍数，m为实际中马数。一家付款的标准金额为：

S = b × F × (m+1)

点炮只由点炮者付一份S；自摸由其余三家各付一份S。不得把普通点炮自动变成点炮者包付三份。

| 结束方式 | 赢家 | 点炮者／各其他玩家 | 旁观者 |
|---|---:|---:|---:|
| 普通点炮，单赢家 | +S | 点炮者−S | 其余两家0 |
| 普通自摸 | +3S | 其他三家各−S | 无 |

四家净分和为0。没有另行确认的庄家额外加倍不自动添加；庄位已明确影响马牌位置、连庄和下一局庄家。

用户给定算例F=6、b=1、m=3：S=24；点炮赢家+24、点炮者−24；自摸赢家+72、其他三家各−24。这里F=6是算例给定最终倍数，不从“清一色”名称擅自再补门清3。

若无中马，m=0，仍付bF，不为0。

### 8.2 普通支付与承包分开

S0所述杠爆点杠者承包、十二张落地自摸承包属于特殊责任，不能被普通点炮只付一家这一公式覆盖，也不能反过来令所有点炮都包三家。

承包触发、责任者、持续范围、与多响冲突及按多少份S结算，仍需Q12冻结。不能用本节普通算例验证承包。

### 8.3 三种牌源的结算时序

先固定本局赢家、胡法、倍数F、底分b、本局庄位／赢家相对编号、付款责任、本次n与N。跨局切换、开马亮牌和重新洗牌不能覆盖这些快照，也不能重复支付。

**同局旧墙足够（R≥N，优先级最高）：**固定终局 → 按最后实际摸牌锚点取N张 → 按本局赢家位置算m → 计算S与付款账本 → 进入下一局。N>14不改变本分支；不读取下一局手牌作为此次马牌。

**下局手牌开马（R<N且N≤14）：**固定终局及待结算单 → 按本局赢家确定下一局庄家 → 生成下一局实际牌序并按原始顺序发牌 → 选取赢家原始前N张，K=N → 用上局冻结位置算m并只亮命中牌 → 完成上局付款 → 这些牌保持在下一局手牌中继续打。不使用任何旧墙余牌混补。

**专门开马再洗牌（R<N且N>14）：**固定终局及待结算单 → 专门开够相应N张，K=N → 按上局位置计算m并结清上局 → 重新洗牌并记录新的实际对局牌序 → 按已确定庄家和累计n开始下一局。该结算阶段不增加n，不占一次真实胡／流局事件。超出一副牌容量时仍须先取得专项处理规则。

以上是对已给规则的数据依赖整理，单赢家场景适用；一炮多响、承包、散场尚未定义的部分不能由此补值。待结算单需唯一ID，分别引用计分所属局、马牌来源局或专门开马阶段，以及实际下一局牌序；中断恢复必须复用已确定的来源与结算结果，而非重新抽马直到得到另一结果。

N=6的明确算例：本局乙为1号，F=6、b=1，胡后旧墙3张；乙下一把前6张为`二万、六筒、南、四条、东、九万`。按上一局1号命中前三张，m=3、S=24；普通点炮只付24，自摸三家各付24。亮出前三张后仍在乙手中；剩余旧墙3张不用于混补，东与九万不因新庄身份计入旧局马数。

在牌源尚未实际确定前，m和最终S是待结算，不是0。实验停止、程序恢复或不再开下一把时不能直接丢弃该笔回报；散场具体房规仍见Q13。

## 11. 牌谱、模型观察与实验影响

### 11.1 牌谱单一事实源

应记录固定玩家ID、本局和下局相对位置、庄家及连庄状态的前值／增量／结算使用值／后值，更新原因区分胡牌、流局保留、闲家归零，专门开马／再洗牌不算一次连庄事件。

行牌记录保留初始牌序、原始发牌事件、摸打完整事件、胡牌前结构及来牌来源；计分保留项、包含去重与门清资格；最后摸牌锚点、墙端和位置；胡牌摸前与摸后剩余数。海底判定引用摸前值，并关联原胡牌事件。

开马记录保留要求N、实际K、旧墙可取R、选择分支及原因、计分所属局ID、来源局ID或专门开马阶段ID、实际马序列与实体ID、原始到手次序、逐张归属、命中掩码、按上局位置得出的m、F、b和每笔付款。

跨局手牌的公开事件只携带实际亮出的命中牌和持有人，不携带未亮牌的身份。私有审计区可以保存完整牌序和命中判定证据；对手Actor必须通过公开投影读取。亮马牌留在手中，其已公开历史应保留，后续弃牌／碰杠按真实事件更新；不能在新局开始时把已亮牌信息全部清空。

原始发牌顺序与理牌排序分开保存，不能通过重排手牌影响选马。亮牌与副露分开，亮马不自动改变牌型资格。对手仅获得实际公开的身份／数量／持有人信息，不强行暴露未公开的牌位索引。

待结算单ID和唯一支付标识用于恢复与去重。专门开马的牌序与重新洗牌后的实际下一局牌序使用不同事件记录；重新洗牌后的具体位置关系不能由上次开马直接确定。

### 11.2 连续对局而非仅独立单手

S5使一局结果改变下一局庄家、相对马位和连庄状态；S7使某些上局金额依赖下一局实际起手牌；S8明确部分命中马亮出且继续留手，又增加下一局合法公开信息的变化。单手受控评估必须声明起始庄家、n、公开信息和结算完成方式，不能在胡牌瞬间截断抓马，也不能每局清零这些状态后声称覆盖真实连续玩法。

账本归属应将延迟得分记回产生它的上局，不记成下一局新胡牌奖励；模型决策时不能提前知道尚未产生的马牌或下一局手牌。训练如何承载延迟回报、完成真实结算后再截断，以及公开马牌如何进入防守决策，属于后续实现。N>14的专门开马阶段已明确，但不能据此替代Q13尚未定义的其他散场情形。

未来评估应同时报告单手受控结果与完整连续对局结果。训练优化单局净分还是连续对局累计净分，属于研究协议待确认项；本稿不擅自改变目标。

### 11.3 旧实验边界

旧Mini-PDH把CLOSED作为独立牌型、取最高单牌型计分，并采用点炮赢家与点炮者三份单位的结算。这些与本稿的门清限定、兼容叠加和普通点炮一份付款不一致。旧模型统计只能描述旧环境。

旧代码、Checkpoint和日志保留为原始工程证据，不重写旧得分，不声称旧模型已经掌握本房规，也不靠在旧评估JSON上乘一个系数修复不同决策轨迹。

下一步先确认关键未决项，形成可执行房规与合法测试牌例，然后修正规则引擎、逐局牌谱、并行采样和新规则训练。当前文档更新不授权启动新的云训练或修改已归档实验。
