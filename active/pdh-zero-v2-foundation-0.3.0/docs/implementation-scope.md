# 第三批实施契约

消费者：规则确认者、下一位引擎开发者、结算与牌谱维护者。

本包版本为`0.3.0-foundation`，在0.2.0基础上落实S11。仍不修改旧v1.1.1、旧Checkpoint、旧实验、服务器`env.sh`，也不提供训练入口。

## 本批新增实现

- 一炮多响旧墙不足时不借任何赢家的下一把手牌，固定选择完整新牌序开马；抓马后需要重洗，但不会额外增加连庄。
- 多响账本支持BEGIN/BIND/PAY三阶段、统一马牌逐赢家算m、幂等支付和JSON快照恢复。
- 十二张落地责任只由第四次碰牌触发；第四碰放碰者锁定为责任者。
- 三碰后暗杠、直接明杠、点杠或加杠不会触发第四碰责任。
- 责任只覆盖同一手内碰牌者自摸；点炮胡仍由实际点炮者支付普通一家费用。
- 第四碰责任可进入同一结算账本并随快照恢复，不跨手、不重复支付。

## 仍然不实现

- 杠爆、连续杠、加杠、抢杠的专项责任锁定与解除。
- 完整胡牌评分器、完整`env.step`、Actor/Critic/PPO、并行Worker和训练launcher。
- `rules/open_decisions.json`中的其他未决房规。

## 验收边界

通过测试只表示上述纯函数、账本、恢复和责任契约成立。`training_ready=false`、`full_rules_frozen=false`继续保持。
