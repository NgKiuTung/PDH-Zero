# 0.3.0 手工业务/代码复审

结论：本批新增代码与 S11 已确认房规一致，可作为 CPU 参考基础继续开发；仍不具备正式训练资格。

复审重点：

- 一炮多响始终使用同一批马牌；赢家按各自在计分所属局的相对庄位分别计算中马数。
- 旧墙不足时不借任何赢家下一把手牌，改为完整专门牌序；计划显式标记抓马后需要重洗，且重洗不构成额外连庄事件。
- 庄家在多响赢家中则续庄；否则相对位置号最小赢家成为新庄，其余同响赢家不携带连庄资格。
- 十二张落地展示计数与承包触发分离：公开刻/杠组按每组3张展示，只有三次碰来源后的第四碰锁定责任者。
- 暗杠、直接明杠和加杠不触发第四碰责任；责任仅在同一手内覆盖触发玩家自摸三家份额。
- 触发玩家点炮胡时，第四碰责任不生效，实际点炮者支付普通一家费用。
- 普通、多响和十二张责任账本均按BEGIN/BIND/PAY事件恢复；重复相同调用幂等，改变牌源或快照内容会拒绝。
- 修复了十二张责任账单在已经绑定/支付后再次BEGIN时的幂等性，避免把合法重试误判为冲突。
- 倍数与付款不设人为封顶；流局零点数但保留审计事件。

保留阻断：完整行牌事件尚未自动调用第四碰锁责；专门开马后的实际重洗与下一把状态尚未接入完整游戏状态机；Q12中杠爆/连续杠/抢杠边界及其他 open_decisions 仍未封板。
