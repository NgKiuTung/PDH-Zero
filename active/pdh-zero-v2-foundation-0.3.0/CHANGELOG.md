# Changelog

## 0.3.0-foundation — 2026-09-30

- 房规源升级到v0.8（S11）：多响旧墙不足时统一新开一副牌，抓马后重洗且不增加连庄。
- 多响牌源规划不再借任一赢家的下一把手牌；新增多响账本、幂等付款和快照恢复。
- 十二张落地责任冻结为“第四碰放碰者、同局自摸三家份额”；暗/明/加杠不触发，点炮胡走普通一家付款。
- 新增第四碰责任账本与恢复；责任不能跨手。
- 规则追踪扩展到115项，关闭Q11a并将Q12缩小为杠爆/抢杠剩余边界。
- 正式训练仍禁用。

## 0.2.0-foundation — 2026-09-30

- 房规源升级到 v0.7（S10）：允许一炮多响；共用一批马、各赢家按本局位置分别算马；庄家胡则续庄，否则最小相对位置赢家下庄。
- 增加普通一炮多响纯支付算术与共享马牌选择，不为每位赢家重新抽马。
- 十二张落地按公开刻/杠面子组数×3计；加杠不增加落地张数，明杠作为一组仍只计3张。
- 增加显式责任者“承包三家”纯支付函数；自动责任触发与持续范围继续阻断在Q12。
- 去除人为倍数上限，明确不使用20倍等房间封顶。
- 流局零点数但进入事件账本，并支持JSON快照恢复。
- 新增对应回归测试；正式训练仍禁用。
