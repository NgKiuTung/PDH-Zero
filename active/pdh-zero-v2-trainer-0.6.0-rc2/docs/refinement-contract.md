# 0.6.0-rc2 受控稳定性修订契约

消费者：训练执行者、代码审核者、后续实验维护者。规则来源不变。

## 权重与实验身份

只接收schema=1、规则哈希一致、update=0且metadata.teacher_hands>0的项目warmup。
加载使用CPU映射和受限weights_only模式；模型结构严格匹配且所有参数有限。
导入后risk_policy_weight显式改为0，因此新初评是唯一同协议比较基准；不能借用旧聚合数。
克隆独立的冻结Actor作为KL参考，不共享GRU状态。初始化新的AdamW，weight_decay=0。
实际模型配置、旧配置、来源SHA256、优化器策略和StablePPOConfig写入运行清单。

## 更新与风险

一个完整采样批次固定策略版本；只采集当前学习者座位作为PPO样本。
完整手局序列从初始记忆重算，验证选中动作的行为log_probability与采样时一致。
超过5e-4则报错，不带着不一致的on-policy假设继续训练。

PPO默认clip=0.1、两轮、学习率5e-5、熵系数0.003、参考策略KL系数0.05。
KL比较排除只有一个合法动作的强制决策，避免大量PASS稀释漂移。
每个minibatch前检查KL，完成后重新计算完整批次KL；超过0.01回滚模型和优化器。
被拒绝更新计入已采集样本和尝试更新数，不伪装成已接受优化器进度；下一次步长减半。
连续3次拒绝结束调优。本次没有自动课程晋级、没有突然BC复习、没有自动长训。

risk_pair输入detach，监督损失不回流共享Actor编码器。风险输出不干预Actor。
唯一选中弃牌按实际点炮记录标签；抢加杠不能把此前无关弃牌标成正样本。
BCE不加类别权重，报告正样本比例、Brier、logloss、分组AP、ECE及固定阈值召回/精度。
无正例时AP为null。指标是同批训练诊断，不冒充独立校准集表现。

## 并行与生命周期

CPU环境使用spawn，子进程禁止创建CUDA上下文；一个主进程做批量推理与学习。
环境编号、随机种子、行动顺序映射固定；结果不依赖worker完成顺序。
DecisionView按状态缓存，动作后失效；不在requests与step重复编码相同局面。
worker通过有界Pipe通信；异常/超时使本任务失败，不丢弃问题牌局重抽。
只回收本进程登记的子进程，不全局pkill。

训练开始前检查同输出根任务锁和GPU占用。锁保护同一个输出根，跨根CPU任务不由本锁管理；
GPU检查是启动时快照，不是整台服务器的抢占锁。执行者必须保持约定的GPU独占。
不改旧current指针，任务目录含微秒时间标识且禁止覆盖。
信号处理器只设停止标志，在可清理边界退出，stopped与failed区分。
未提交更新回滚；已完成手局仍记录；尚未完成的牌局不冒充完整牌谱。
保存环境快照用于审计，但本CLI没有resume接口，不承诺强制断电后继续当前未提交批次。

## 评估与数据

baseline和后续候选使用同一组(wall_seed,candidate_seat)，每seed恰好四座位。
每个波次重新初始化手局状态，避免“快完成的局多轮换、慢完成的局被遗漏”。
评估worker跨波次复用，数目变化时才重新启动；不足满批照常推理，不能死等。
每手保存score、赢家身份、点炮者身份、终局方式、seed、seat和状态摘要。
私有牌谱保存初始墙、行动、初始公开留手牌和结算审计；未公开手牌不进入Actor特征。
`tools/audit_replays.py`对手局回放和独立结算账本同时核对；遇旧格式不静默跳过。

门禁基于候选减基线：净分提升至少0.1且牌墙组bootstrap区间下界>0，
点炮率差区间上界≤0.01，才为PASS；净分区间上界<0或点炮率差下界>0.01为REGRESSION；
其余INCONCLUSIVE。这是重复开发集的内部筛选，不是通用显著性证明。
每次评估保存逐手结果、摘要和哈希，可独立重算；多种子/新盲测尚未执行。

## 预算和已知限制

默认总墙钟5400秒、目标750000学习者决策、剩余磁盘下限8GiB。保留最终评估预算。
检查发生在采样、minibatch或进程通信等边界，CUDA调用和文件提交期间不硬杀进程。
未完成的评估保持partial，无完整结果就不晋级。
主奖励仍为按手计算的真实净分；连续环境不等于已完成跨手长期优化算法。
本次不重新生成教师数据；暖启动文件丢失时应停止并报告，不改用失败latest。
