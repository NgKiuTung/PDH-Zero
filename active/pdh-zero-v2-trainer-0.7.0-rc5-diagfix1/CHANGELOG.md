## 0.5.0-rc3 — 2026-09-30

- 修复从 CUDA Smoke 检查点启动长任务时，`map_location=cuda` 将 CUDA RNG 状态迁移为
  GPU Tensor，继而触发 `RNG state must be a torch.ByteTensor` 的问题。
- CPU 与 CUDA RNG 状态现在统一规范化为一维、连续的 CPU `torch.uint8` Tensor 后再恢复；
  同一修复同时覆盖 Smoke 暖启动和长任务恢复。
- worker 在加载检查点前写入 `initializing` 状态，初始化失败会写入结构化 `failed` 状态。
- `status` 在进程已退出但状态仍处于启动阶段时返回 `failed_startup`，并携带 stderr 尾部。
- 启动器等待 worker 报告 `running` 或 `failed`，避免延迟崩溃被误报为已启动。
- Smoke 规则哈希、模型结构和检查点格式保持兼容，无需重新跑 10 分钟 Smoke。
