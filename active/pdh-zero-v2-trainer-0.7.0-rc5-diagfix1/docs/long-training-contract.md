# 长训练契约状态

0.5.0-rc3 的首轮长任务已安全停止，原因是训练手局终局信号过稀疏，而非程序崩溃。
该任务目录、检查点、牌谱和评估全部保留为负基线。

0.6.0-rc1 不提供新的长训练启动许可。`tools/long_job.py start` 会拒绝执行；只有
`tools/train_curriculum.py` 的目标 GPU 调优通过 `tools/curriculum_gate.py` 后，才基于
实际吞吐、收益、点炮率、流局率和磁盘体积生成新的长训练预算与恢复契约。

现有 `status`、`stop`、`resume` 子命令只为旧任务维护保留，不应把旧 0.5.0 检查点加载到
新观察维度和新模型结构中。
