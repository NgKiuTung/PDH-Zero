## 2. 正常Actor和私有标签两条路径

正常Actor的输入仍为622维合法观察、74维候选动作、384维局内GRU。对手公开区按下家/对家/上家分出3×102维，含弃牌/副露/公开留牌；局内GRU按该玩家合法决策时点更新。未新增无损完整事件序列编码器。

训练/审计私有路径重放完整牌谱并核验终局摘要和账本。每个时点只保存当时合法观察与当时GRU；另一namespace保存对手暗手产生的监督目标。未来行为在完整重放结束后仅填入标签，不改先前特征。全会话分组切分防止相邻预发牌分跨TRAIN/辅助验证。辅助验证来自旧训练侧，不能称为对rc4.1 Actor未见。

当前辅助v2来自训练归档前512完整手，165122动作事件、13953采样，11344训练、2609辅助验证；52/12个整会话。原96手v1及H1拟合保留为历史，旧行动标签受强制PASS影响；v2预测下一次有选择的动作，不是第一条强制PASS。v1/v2目标不同，不横比CE声称某项改动有效。

## 4. 自身多路线与三家联合决策

旧Actor所有权重严格复制。新增最终层全零的残差MLP：74维动作 + 8维自身当前结构 + 459维三家预测 + 192维“自身候选后8路线×每家8路线”交互 + 12维对应牌种的接炮/碰/杠/弃牌预测，共745维。多条路线并存，通过可学习非线性共同影响每个合法动作，而不是先选一条路线或固定扣三个风险分。

旧特征/动作枚举/房规保持；没有扩写一套全新何切搜索树或声称看遍所有未来胡牌路径。残差只靠旧稳定PPO的真实净分学习；辅助监督不回传旧Actor、PPO也不改辅助头。尚未通过预测门禁的通道只保留训练先验。

零初始化联合分支、诊断分支与旧策略初始logit/GRU精确相同。保留原state key，rc5候选使用独立schema与SHA；旧工具不能直接加载新schema。每次PPO之前的有效候选与每次实际提案都留下；即使KL回退也不删除提案。优化器/模型回退使用原稳定实现，不承诺进程精确resume。

预测头在原基线GRU特征上拟合；后续PPO可能带来隐状态分布漂移。每个冻结评估后的逐家预测诊断只读、不再拟合或改门禁；因此初始辅助资格不应被当作所有新对手和所有后续策略下持续校准的保证。

## 5090 diagnostic negative-control correction

`diagnostic` is an instrumentation control, not an independent policy optimization arm.
After the baseline arm has produced each same-seed PPO update, the diagnostic arm collects
the same declared natural-hand budget and then mirrors only the legacy Actor tensors from
that baseline effective checkpoint. Its fitted belief head remains read-only to policy.
The final gate still requires bit-exact Actor tensors and exact trajectories for all three
opponent conditions; no numeric tolerance is used to hide CUDA drift.
