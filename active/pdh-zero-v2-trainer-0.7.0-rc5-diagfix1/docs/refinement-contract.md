# 0.6.0-rc3 训练、候选与验证契约

消费者：训练维护者、评估审核者。部署与命令以README为准；此处定义实现边界。

## 身份和不变项

冻结房规SHA256：`141126f0485fa34d9d91dca72e7b3d45a8c38c3d19ef461cab7760fae43c04bc`。
原始支付、无封顶和抓马规则不变。warmup使用受限weights_only CPU加载，拒绝错误房规、
非零update、缺少teacher_hands或非有限参数；新建AdamW，不继承BC动量。
原网络的width/observation/action尺寸保持；effective risk_policy_weight为0并重新评估起点。

## 更新约束

完整手局重算GRU历史，行为log概率误差必须≤5e-4；只有当前策略座位进入PPO。
post_update_kl比较采样策略与更新后策略，排除强制单动作；默认硬阈值0.01。
proposal_anchor_kl比较冻结warmup与拟提交策略，也在完整采样批次、非强制动作上重算。
默认硬上限0.12。任一越界，恢复模型和优化器，不把拒绝的尝试当成已接受优化。
异常和主动停止也恢复更新前状态。风险监督的输入detach，不能更新共享Actor编码器。

日志的anchor_kl保留为小批训练过程均值；proposal_anchor_kl为更新后完整批次值；
effective_anchor_kl为提交后值（回滚则为更新前值）。不同批次局面分布不同，
不能仅比较两个时点的KL比值便推断策略因果退化。

以effective_anchor_kl/0.025限制在[1,8]作为有界调节量：
下一批anchor系数为初始0.05乘该量（0.05～0.4），学习率为初始lr除其平方根，
且不低于初始lr/4。同一个KL重复出现不会指数衰减。
拒绝时还有减半步长；连续三次拒绝结束。阈值和系数均是明确记录的实验配置。

## 候选保存与选择

每个评估点先复制已提交checkpoint到独立candidate目录，校验SHA256，再执行评估。
INCONCLUSIVE、评估中断、尚无结果都不能删除或覆盖该文件。候选标签不能是任意路径。
完成评估后绑定逐手结果哈希、摘要与门禁，已绑定结果不可重复提交。

开发选择与资格分开。名义候选要求比当前选中的均分至少高0.1，点炮点估计不超过
baseline+0.01，CVaR点估计不低于baseline−风险容忍值，且非REGRESSION。
qualified只接受完整配对门禁PASS；两者都不自动开启长训。
连续两次不产生名义候选改善时提前结束是预算策略，不证明真实学习曲线已经平台。
程序独立导出selected_development，不把latest称为最优，也不伪装已回滚并继续训练。
CLI不支持精确resume；源环境快照仅供审计。

## 评估、风险与账本

同一牌墙恰好四座位、相同初始庄位和零连庄，记录完整逐手结果及私有牌谱。
重建终局SettlementBook，逐笔支付与receipt对账，普通点炮、被自摸、抢杠、多响、
十二张责任、点杠责任分别统计；倍率、马放大、支付份数是正交解释，不能重复加总。
最差手局只保存到权威results的索引，不能凭最低分猜出责任事件。

配对bootstrap以牌墙为单位。CVaR差通过每次重采样后重新计算两组下尾均值取得，
不错误地把每一组的四张牌局CVaR先取平均。报告单次开发区间，不宣称已控制全部重复查看误差。
新牌墙验证先冻结候选和规则，检查实际开发key与本输出根的既有reservation；
中断预留不会删掉。更换目录规避登记不能改变数据已暴露的事实。

## 共享传输与生命周期

spawn Worker只生成CPU规则环境；合法float32观察与动作特征写入固定共享RawArray，
控制元数据仍经Pipe。主进程复制进当前轨迹，防止下一轮写缓冲篡改已保存经验。
最多64个候选动作；超限报错而不是截断合法动作。串行、Pipe、共享模式行动次序一致。
RPC计时包含工作与等待，不作为纯序列化开销；GPU端到端收益须实测。
异常回收本任务登记的PID，禁止全局kill。CPU任务锁只覆盖相同输出根，GPU检查为启动快照。
信号置标记、在边界清理；保存完整候选和已提交更新，不宣称中断批次无损恢复。

## 验收边界

CPU夹具验证权重保存、信息隔离、支付账本、串并行等价和控制逻辑。
本次没有用户真实warmup或83MB实验归档，也没有RTX 5090，因此不报告真实新模型增益、
真实尾部事件归因或CUDA性能。统计提升、GPU验收、跨训练种子复现仍待目标实验。
