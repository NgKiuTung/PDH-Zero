# 课程学习调优契约

版本：0.6.0-rc1

## 背景

0.5.0-rc3 在 6,152,009 学习者决策处安全停止。工程路径正常，但自然开局的四家弱策略
纯自博弈长期保持约 99% 流局，固定评估仍为负收益且点炮率偏高。该结果作为负基线保留，
不得恢复相同配置继续消耗预算。

## 目标

本阶段只回答三个问题：

1. 更强的规则教师行为克隆能否提供基础做牌能力；
2. 启发式锚定的混合对手课程能否显著降低训练流局率并产生有效终局信号；
3. 多路线表示与点炮风险辅助能否在不泄露隐藏信息的前提下改善固定评估收益—风险。

## 数据与 on-policy 边界

- 每手由课程选择1至4个学习座位，其余座位使用冻结规则启发式。
- 只有当前策略实际控制的决策进入 PPO；启发式动作不伪装成当前策略样本。
- 四家终局账本、流局和完整牌谱全部记录，即使某座位没有学习动作也不从业务统计消失。
- 课程阶段只在完整 PPO 更新边界切换；同一手不混用两个控制方案。

## 默认阶段

| 累计学习者决策 | 阶段 | 学习座位数量权重（1/2/3/4） |
|---:|---|---|
| 0 | GUIDED_SOLO | 1.00 / 0 / 0 / 0 |
| 250,000 | GUIDED_DUO | 0.55 / 0.45 / 0 / 0 |
| 750,000 | GUIDED_TRIO | 0.15 / 0.45 / 0.40 / 0 |
| 1,500,000 | ANCHORED_SELF_PLAY | 0.10 / 0.20 / 0.30 / 0.40 |

最终阶段仍保留启发式锚点，不会立即退化为四家同一弱策略的单一分布。

## 模型与辅助目标

- 共享 Actor-Critic，四座位独立 GRU 隐状态。
- 八条路线潜力、四类历史资格、候选动作后路线变化与公开风险进入合法观察。
- 风险标签只标记学习者真实弃牌：普通弃牌为0，实际导致点炮的那一次弃牌为1。
- 风险 BCE 带正样本权重；风险输出初始为中性，且策略损失不反向篡改风险头的校准。
- 主奖励仅为真实净分；不增加碰杠惩罚、门清奖励或人为向听分。

## 晋级长训练

课程任务完成后，`curriculum_gate.py` 必须通过。门禁至少要求：

- 任务完整结束并产生多个 PPO 更新；
- 教师验证准确率至少65%，且行为克隆不得导致超过1个百分点的退化；
- 至少两次固定评估；
- 末段混合对手流局率不高于90%；
- 末段所有合法胡牌机会聚合后的捕获率不低于98%；
- 固定评估平均净分较初始提高至少0.10；
- 固定评估点炮率未恶化超过1个百分点；
- 损失、KL、熵和梯度均为有限值。

通过后另行生成长训练包；本候选不允许直接 `start` 长任务。
