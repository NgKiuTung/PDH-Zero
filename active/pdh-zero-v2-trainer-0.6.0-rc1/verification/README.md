# 0.6.0-rc1 验证证据

本目录只保留当前课程学习候选的发布门禁证据。旧 rc2/rc3 包及其验证记录继续保存在
各自独立发布包中，不在本包复制。

当前版本允许目标 RTX 5090 上运行 60 分钟课程调优，不允许直接创建新的正式长任务。
长训练包必须在 `tools/curriculum_gate.py` 对目标 GPU 产物返回 PASS 后另行生成。

本地发布门禁包括：233 项完整测试、Python 3.10 AST 解析、基础静态审计、冻结规则与
训练专项验收、课程模块定向行/分支覆盖率、启发式终局密度检查和两秒 CPU 集成 Smoke。
`ruff` 与 `mypy` 在离线构建环境中未安装，因此明确记录为 `NOT_INSTALLED`。
