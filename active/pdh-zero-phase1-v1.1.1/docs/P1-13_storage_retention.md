
# P1-13 存储与保留策略

| 阶段 | 推荐数据盘 |
|---|---:|
| Gate A-C 与 Mini-PDH | 50GB |
| Full-PDH 主方法筛选 | 100GB |
| 多种子、消融与长期日志 | 200GB 或外部归档 |

必须长期保留：发布包及 SHA256、Manifest、配置、指标、stderr、最佳/最新/论文 Checkpoint、固定评估种子、统计脚本与图表输入。

禁止长期保存：每一步原始 Transition、重复缓存、无法关联配置的匿名 Checkpoint、未打包的调试文件。

数据盘适合在线训练；文件存储或本地适合长期备份。实例释放前必须验证备份 SHA256。
