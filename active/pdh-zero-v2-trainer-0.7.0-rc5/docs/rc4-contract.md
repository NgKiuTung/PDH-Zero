# rc4实现与实验合同

## 单一规则来源与兼容性

冻结规则来源`rules/source-v0.9.md`及现有Python规则/计分/账本未改。C++只实现合法投影的数值计算和启发式评分，不执行发牌、响应优先级、判胡、抓马或付款。Python是慢速差分参考，不存在独立维护的新房规。观察622、动作74、hidden384及参数名保持兼容。

CPP输入只含行动玩家暗手和原Python投影中的公共状态；不包含其他玩家暗手或未来牌墙。副露链中的审计真值只进入牌谱，不能成为Actor输入。全部合法动作由Python枚举，C++接受一次批量的状态/候选列表，返回连续数值数组。边界拒绝错误dtype、形状、偏移、玩家、实体牌与超过容量的动作，绝不截断合法动作。

## 数值与生命周期

使用C++20/GCC，禁用fast-math和隐式FMA重排，不绑定特定AVX指令集。目标机本地编译pybind11扩展，仅依赖Python.h、PyTorch打包的pybind11头，无libtorch/CUDA链接。导入验证SOABI、源文件哈希、二进制哈希；源码变化需重编。GIL仅在纯数值C++段释放。输出数组由调用侧持有，不能返回指向局部内存的悬空视图。

差分约束：整数状态/动作顺序/老师argmax/终局摘要严格一致，浮点特征rtol=0、atol=2e-12。本地64手真实d265牌谱覆盖18484决策；另有OpenKong专用回归。有限样本差分不证明全部可能状态均已形式化验证。

## 资源与负载策略

官方14vCPU与日志一致：1400000/100000=14；60GiB内存是cgroup上限。读取可见cgroup祖先及affinity更紧限制，未知配额以声明14作保守上限，绝不将宿主128视作授权。低配自动缩减Worker候选。

准备阶段按单个负载配置顺序执行；每个配置的进程组独立登记，只清理自身进程。不在任务间全局kill Python/Node等。测量包括全部采样逻辑与真实模型推理，不包括优化器，启动时间另报。固定种子/模型/桌数使所有配置终局可比。全局cgroup计数包含同容器其他任务，不能解释为单个Worker精确性能。

默认2/4/6/8/10/12 Worker、64桌、两次重复；14核中保留约2份CPU时间预算，BLAS/Torch单线程。四种以上配置不是同时启动的四份训练。纯Python参考必须完成；CPP语义不一致不得选为计划。容量降低、模型/源码/ABI/设备变化需重新准备。OOM/超时等测量失败明确停，不在失败后继续启动更高负载。

短测只能识别候选负载，不能保证最佳吞吐。正式运行的生产吞吐要同时报告学习者决策/秒、环境决策/秒、采样/学习/评估分阶段时间。计划不把GPU功率作为优化目标。

## 权重与训练

输入必须是完整rc3运行目录的selected_development.json，核对candidate.json、权重SHA256、results.jsonl SHA256。不能从未评估或篡改latest导入。实际接收的d265095权重SHA256为2688e2d6427e97179d69c80126d0dac216ce1d2d5827e82ef357274da358b948。

此候选仍为INCONCLUSIVE。rc4新baseline/冻结anchor均为本轮输入模型；重新建AdamW，不继承先前动量，保持风险权重0。网络、PPO损失、真实净分奖励、SOLO课程和rc3门禁不同时改动，便于解释差异。本版不做反事实续局、风险头接回、异步off-policy采样、DUO或完整C++游戏引擎。

## 自责分/防御率

直接责任类别：ordinary_discard、discard_multi、rob_kong、twelve_grounded_liability、kong_draw_liability；普通自摸分担ordinary_self_draw独立统计。不属于这些类别的付款直接报错，不能静默归零。对每个玩家—手局，所有入账减所有出账必须等于原score。每笔本金+中马增量=付款。多响付款逐笔累加、责任手局计数一次。

百局防御率=100×直接责任支出/玩家—手局数，越低越好；统计分母及方向写入报告。它不等于合理决策错误率，不能替换真实净分奖励。普通自摸分担不意味着因果零贡献。全样本损失占比不等于尾部局损失占比。

供牌链仅由实际面子状态变更产生；暗杠没有外部provider，加杠保留最初Pong链接、不重复新增外部供牌。记录资格/路线数值变化而不擅自判定行为好坏。反事实贡献度NOT_ESTIMATED。

## 统计与发布边界

反复开发牌墙不用于确认性结论。区分开发首选、完整门禁通过者和latest；所有评估节点永久保存。核对候选时不因差一点过门槛而事后放宽。责任指标仅监测，不自动加入旧安全门禁。

本地CPU测试、真实权重兼容及原牌谱审计已做；目标CUDA性能、14vCPU负载排名及模型收益未做。没有精确resume，只有完整已提交更新；中断先关闭自己的Worker。导入rc3候选不会补回rc2未保存的中期权重。
