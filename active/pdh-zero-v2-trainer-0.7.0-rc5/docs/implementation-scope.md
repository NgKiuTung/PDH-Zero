# 0.6.0-rc1 课程学习实施范围

## 已交付

- v0.9 冻结房规、136张完整状态机、连续庄位／抓马／责任结算与可重放牌谱。
- 合法观察、候选动作 GRU Actor-Critic、PPO、检查点与目标 CUDA 运行基础。
- 显式多路线／资格／公开风险特征。
- 1至4学习座位与启发式对手混合的确定性课程。
- 强化行为克隆、周期教师复习和点炮风险辅助。
- 学习者与全桌决策分离、攻防业务指标、周期固定评估。
- 60分钟 RTX 5090 调优入口与自动晋级门禁。

## 本版明确不交付

- 新的正式长训练启动器；旧长任务启动在本版本中被阻断。
- 多进程环境推进；当前仍为单进程多桌参考引擎。
- 已验证有效的论文方法结论；多路线和风险辅助仍须目标 GPU 实验。
- 特权 Critic 正式对照；等公开历史基线先通过课程门禁。

## 验收定义

- `engine_check=PASS`：冻结规则参考引擎通过 CPU 门禁。
- `training_candidate_check=PASS`：模型、课程、PPO、牌谱和检查点通过 CPU 门禁。
- `curriculum_entry_ready=true`：允许目标 RTX 5090 课程调优。
- `long_job_entry_ready=false`：禁止从本版本创建新的正式长任务。
- `curriculum_gate=PASS`：允许开发下一版长训练包，不代表论文结论成立。
