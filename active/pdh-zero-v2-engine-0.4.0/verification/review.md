# 0.4.0 发布前复审

## 结论

冻结规则 CPU 参考引擎通过 204 项自动测试、Python 3.10 语法解析、无依赖静态审计和 300 手随机合法动作压力测试。房规来源哈希一致，`engine_ready=true`、`full_rules_frozen=true`、`training_ready=false`。

## 复审中发现并修复

1. 跨局中马亮牌曾可能按牌种扩大到未被选中的同类实体；现仅标记实际前 N 张内命中的实体，并写入公开会话事件。
2. N>136 专门开马会跨重洗轮次复用实体编号；账本绑定与快照恢复现按每个重洗周期校验，不再误判跨周期重复。
3. 终局对象原先对胡法、付款者、赢家重复和旧墙实体约束不足；现于边界统一拒绝不一致终局。
4. 牌谱动作原先会忽略未知字段；现使用严格动作 schema，并将完整计分解释纳入最终状态摘要。
5. 规则源仍残留早期“待确认”描述；已按 S12 改为冻结语义并更新全部哈希。

## 已知工程边界

- 当前仅为 CPU 规则参考引擎，不包含 Actor、Critic、PPO 或 GPU 训练入口。
- 连续会话全量 Checkpoint、公开／私有观察投影和大规模牌谱分片尚未实现。
- `ruff` 与 `mypy` 在当前环境不可用，未伪造通过；无依赖静态审计无硬错误，但仍报告大文件和长函数软警告。
- 随机压力测试只证明状态推进和牌实体守恒，不证明策略质量或稀有牌型分布。
