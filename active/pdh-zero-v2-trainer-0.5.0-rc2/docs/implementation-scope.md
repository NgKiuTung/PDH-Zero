# 0.5.0-rc2 训练与长任务实施契约

消费者：训练执行者、规则审核者、牌谱维护者、算力管理者和后续方法开发者。

## 已交付

- v0.9 冻结房规参考引擎与136张完整状态机。
- Actor合法观察、独立座位GRU、多桌批量推理、启发式暖启动和Recurrent PPO。
- 10分钟CUDA Smoke入口、全量紧凑牌谱、结构化指标和训练检查点。
- Smoke晋级门禁、默认48小时／5000万决策长任务、查重、安全停止和精确恢复。
- 长检查点中的环境下一手状态、庄位／连庄、RNG、预算、周期评估和快照游标。
- 逐更新原子牌谱、孤儿数据隔离及可重建指标视图。

## 尚未由发布包替代的外部验收

- 目标RTX 5090上的Smoke是否完成、数值有限、吞吐和存储是否符合预算。
- 48小时基线的实际学习效果与攻防统计。
- 单进程参考采样器之后的多进程吞吐优化。
- 多路线表示、风险辅助头和特权Critic的受控方法实验。

## 验收定义

- `engine_check=PASS`：冻结规则参考引擎通过CPU门禁。
- `training_candidate_check=PASS`：短时训练代码通过CPU门禁。
- `long_job_candidate_check=PASS`：晋级、更新边界恢复、评估与原子牌谱测试通过。
- `formal_long_run_ready=false`：发布包不能代替目标Smoke；启动器会在创建任务前再次验证。

上传实例后，应先完成Smoke。Smoke通过即可直接执行长任务 `start`，不需要人工改写
`env.sh` 或当前旧版活动目录。
