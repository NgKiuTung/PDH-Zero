# 长训练候选契约

版本：0.5.0-rc2

## 目标

目标 RTX 5090 的 10 分钟 Smoke 通过后，复用 Smoke 的模型与优化器状态，建立一个
可暂停、可恢复、预算有界、逐更新原子牌谱落盘的单模型长期基线。

## 默认预算

- 最多 48 小时累计训练墙钟；
- 或新增 50,000,000 个有效 Actor 决策；
- 任一条件先满足即在完整 PPO 更新边界正常完成；
- 每新增 5,000,000 个决策保存周期快照并运行固定启发式对手评估；
- 每个已完成 PPO 更新提交一个 gzip JSONL 牌谱分片；
- 数据盘可用空间低于 8 GiB 时安全停止。

## Smoke 晋级门禁

Smoke 必须满足：

1. `manifest.status=completed`；
2. 冻结房规 SHA256 与本包一致；
3. 更新数、手数和有效决策数均大于零；
4. 最新指标全部有限，四家原始净分和为零；
5. `checkpoint_latest.pt` 存在且可由长任务加载；
6. gzip 牌谱至少包含一条完整记录。

不满足任一条件时，长任务拒绝创建。

## 暖启动与恢复边界

- Smoke 到长任务只继承模型、优化器和更新计数；长任务使用独立环境随机流。
- 长任务在完整 PPO 更新边界提交模型、优化器、Python/Torch/CUDA RNG、全部牌桌的
  下一手状态、庄位／连庄、牌墙 RNG、预算和评估游标。
- 长任务恢复不依赖原 Smoke 目录继续存在。
- 更新检查点之前生成但未提交的牌谱与逐更新指标会隔离到 `orphaned/`；恢复后重算
  当前更新，但孤儿数据不进入正式样本。
- `metrics.jsonl` 是由已提交逐更新 JSON 可重建的便捷视图。
- SIGTERM 只设置停止请求，完成当前 PPO 更新后安全退出。

## 任务控制

- 全局任务锁创建于研究根 `state/`；已有活动任务时，重复启动返回现有任务。
- 状态、停止和恢复使用精确 `job_dir` 与登记 PID，不按最新目录或进程名猜测。
- 不识别的 GPU 计算任务会阻断启动；程序不会自动终止外部进程。
- 磁盘门禁、人工停止和异常不会伪造 `completed`。

## 非目标

- 不宣称首轮48小时训练一定达到论文结论。
- 不以 GPU 利用率作为唯一成功指标。
- 不在同一基线任务中同时改变模型结构、奖励和房规。
- 不把 Smoke 与长任务的外生牌墙流视为逐位连续。
- 不承诺在 PPO 更新中途被强制断电时保留该未提交更新的计算进度。
