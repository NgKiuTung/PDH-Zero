# Changelog

## 0.5.0-rc2 — 2026-09-30

- 新增 Smoke 晋级门禁和默认 48 小时／5000 万有效决策长任务入口。
- 新增长任务查重、精确任务指针、安全停止、后台状态和更新边界恢复。
- 长检查点保存模型、优化器、随机源、全部牌桌下一手状态、庄位／连庄和预算游标。
- 新增逐更新原子 gzip 牌谱、孤儿分片隔离、可重建指标视图、周期快照和固定对手评估。
- 重复启动返回既有活动任务；恢复不依赖原 Smoke 目录继续存在。
- 当前仍要求目标 RTX 5090 Smoke 通过，发布包不将 CPU 门禁冒充正式长跑验收。

## 0.5.0-rc1 — 2026-09-30

- 新增合法观察投影和隐藏信息不变性测试。
- 新增候选动作式 GRU Actor-Critic；每桌每座位独立记忆。
- 新增单进程多桌批量推理、完整手局排空和四家轨迹采集。
- 新增无真人牌谱规则启发式暖启动、Recurrent PPO 和更新边界检查点。
- 新增 gzip 全量牌谱、JSONL 指标、GPU 独占启动检查与限时 Smoke CLI。
- 当前只批准 10 分钟目标 GPU 门禁；正式长跑仍未批准。


## 0.4.0-engine — 2026-09-30

- 房规源升级为 v0.9（S12），关闭 Q1、Q3、Q4、Q5、Q6、Q10c、Q10d_capacity、Q12 与 Q13；`full_rules_frozen=true`。
- 新增完整牌型解释与最高完整解释选择：幺九四类、三元、四喜、七对兼容项、十三幺／十三面、四暗刻、十八罗汉及事件附加。
- 新增 136 张参考手局状态机：传统发牌、墙头摸牌、墙尾补牌、弃牌响应、碰／明杠／暗杠／加杠、只抢加杠、一炮多响和过胡锁定。
- 新增连续会话结算：庄位与连庄、流局零分、三类马牌来源、N>136 分轮重洗、散场虚拟下一把发牌。
- 杠爆直接点杠责任优先于十二张落地，只执行一套承包付款。
- 新增确定性单手牌谱、状态哈希、牌实体守恒门禁、随机合法整局压力工具。
- 冻结规则参考引擎已通过自动测试；Actor、PPO、批量采样和正式训练仍未交付。
